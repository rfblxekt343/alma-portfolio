# Alma — Developer Portfolio

A responsive dark, modern portfolio built with Next.js, React, TypeScript, Tailwind CSS and Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Before publishing

1. Replace the GitHub and LinkedIn placeholder URLs in `src/components/Portfolio.tsx`.
2. Add your real email address.
3. Add your CV as `public/Alma-CV.pdf`.
4. Add genuine project screenshots in `public/images/` and update the project cards if desired.
5. Confirm the project descriptions and technology lists accurately reflect what you built.
6. Do not publish sensitive military, personal, or operational information.

Deploy to Vercel by importing the GitHub repository.
